# SonicTriadStudio
A rewrite of my PyQt6 disassembly editor, which in itself is a remake of my decade-old Sonic Triad editor written in Game Maker 8.1.

Sonic Triad Studio is meant to be used with disassemblies, primarily those of the original trilogy of games (Sonic 1, Sonic 2, and Sonic 3K). It comes with a series of editors, each targeted at different aspects of the games' data.

## Palette Editor
The Palette Editor hosts an array of color modification tools for arrays of up to 256 colors. This is ideal for:
* Character palettes
* Level palettes
* Underwater blend palettes
* Sub-palettes
* Cycling palettes

## Sprite Editor
The Sprite Editor features tools for viewing and editing in-game sprites. Assets are compiled into sprite builds for quick and easy access and editing

## Animation Editor
The Animation Editor allows users to put together animation scripts for their sprites, and watch the animations play out in real-time.

## Level Editor
A robust tool that modifies object placement and layouts for both foregrounds and backgrounds. Direct editing of level art is also done here (This might be split off into its own tool).

## Object Editor
An in-house tool for Object Definitions used in the Level Editor. Sprite builds and emulated VRAM allow you to see exactly how objects are expected to look in your hack.

## Tilemap Editor
An editor for tilemaps, handy for title and menu screens. Direct editing of palettes and art tiles included.

## Special Stage (S1) Editor
A complete editor for the rotating Special Stages in Sonic 1, complete with custom block support.

Planned content subject to change.
